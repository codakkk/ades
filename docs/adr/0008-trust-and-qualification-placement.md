# Trusted-list model and qualification live in the core; custom anchors never qualify

The core holds the trusted-list model, TL XML parsing and signature validation, and the qualification algorithm (TS 119 615, DSS-equivalent output). Qualification is a decide step (ADR-0007), so it must work offline from a TL file. `ades_eu_tl` only fetches the LOTL and national TLs, walks pivot LOTLs from the Official-Journal keystore pinned per release, caches, and refreshes when asked (no background timers). A chain ending at a custom trust anchor always yields qualification NA. Only trusted-list service entries can produce a qualified status, and tests use test TLs for that. The Italian AgID list is the IT national TL with no special code. The pre-2016 CNIPA list format is out of scope.
