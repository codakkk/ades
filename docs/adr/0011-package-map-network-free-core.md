# Package map; the core is network-free by construction

The core `ades` package has no HTTP dependency. It defines source interfaces and the encoding/decoding for RFC 3161, OCSP, CRL and AIA. HTTP implementations live in `ades_online` (on `package:http`, web-compatible), which `ades_eu_tl` builds on. Signing vehicles are separate packages: `ades_pkcs11` (`dart:ffi`, MVP), `ades_soft` (in-memory keys, ADR-0005), `ades_csc` (CSC v2; Italian proprietary remote-signing APIs are left to out-of-repo adapters), and later `ades_cie` (pure-Dart APDU over an abstract transport) with `ades_cie_flutter` as the only Flutter-dependent package. `ades_cli` is the dogfooding and oracle tool. Formats and levels are sealed inside the core. Public extension happens only at the seams: signing credential, crypto provider, sources, cache, document resolver.
